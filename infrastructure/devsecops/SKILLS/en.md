# DevSecOps Skills

- **Pipeline Security** — secure CI/CD environments, use ephemeral runners, sign artifacts.
- **Security as Code** — integrate scanning tools (SAST/DAST/SCA) into every pipeline stage.
- **Vulnerability Management** — use DefectDojo or Dependency-Track to correlate findings.
- **Policy as Code** — enforce security gates with OPA, Conftest.
- **Incident Response Automation** — create playbooks that trigger on security events.
