# Operational Security Skills

- **Security Logging** — log auth events, privilege changes, data access; never log secrets or PII.
- **Incident Response** — triage, contain, eradicate, recover — use playbooks from OWASP Incident Response.
- **Ransomware Defense** — backup strategy (3-2-1), detection rules, recovery drills.
- **Vulnerability Management** — intake findings from scanners, prioritize by CVSS + business impact.
