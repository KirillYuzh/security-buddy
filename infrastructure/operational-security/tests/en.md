# Operational Security Tests

| Check | Method |
| :--- | :--- |
| Log coverage audit | Simulate auth failure, privilege escalation; verify log entry |
| Incident response drill | Tabletop exercise with breach scenario |
| Ransomware readiness | Test backup restoration; simulate ransomware (e.g., `ransomware-simulator`) |
| AppSensor detection | Deploy detection points → verify alert → verify response |
