# WAF & ModSecurity Skills

- **CRS Tuning** — configure ModSecurity Core Rule Set, handle false positives with rule exclusions.
- **Bypass Testing** — test WAF rules against common bypasses (HTTP smuggling, encoding tricks).
- **Custom Rule Writing** — write ModSecurity rules using SecRule language for application-specific threats.
- **WAF Log Analysis** — analyze WAF logs for attack patterns not caught by CRS.
- **AppSensor Integration** — deploy AppSensor detection points and configure automated responses.
