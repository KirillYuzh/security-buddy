# IoT Security Skills

- **Firmware Analysis** — extract and analyze firmware with binwalk, firmwalker.
- **Hardware Hacking** — identify debug interfaces (UART, JTAG, SPI).
- **Protocol Security** — evaluate MQTT, CoAP, Zigbee security configurations.
- **Update Chain Security** — verify signed/encrypted update mechanisms.
- **Physical Hardening** — disable unused debug interfaces, secure boot.
