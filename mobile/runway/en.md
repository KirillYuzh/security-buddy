# Mobile Security Runway

1. **Security by Design** — apply MASVS-L2 requirements for any app handling PII.
2. **CI/CD Checks** — run MobSF static analysis on every APK/IPA build.
3. **Dependency Scanning** — check Gradle/CocoaPods dependencies for known CVEs.
4. **Penetration Testing** — use MASTG test cases as the acceptance criteria for manual reviews.
5. **App Hardening** — implement obfuscation, integrity checks, and certificate pinning before production.

See: [OWASP Mobile Security Project](https://owasp.org/www-project-mobile-security/)
