# Supply Chain Security Skills

- **SBOM Generation** — produce CycloneDX SBOMs for every build with `cyclonedx-bom` or `trivy`.
- **Vulnerability Correlation** — feed SBOMs into Dependency-Track for continuous monitoring.
- **Provenance Verification** — verify package signatures (`cosign`, `npm audit signatures`).
- **License Compliance** — use `license-checker`, `scancode` to validate OSS licenses.
- **Dependency Freshness** — monitor for outdated packages with `npm outdated`, `pip list --outdated`.
